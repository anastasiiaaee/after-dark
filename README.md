# AFTER DARK

Десктопное портфолио Анастасии. Vite, Vanilla JavaScript, CSS, Canvas. Основной размер проверки — 1920 × 1080.

## Запуск

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Медиа и анимация

`public/frames/` содержит все 180 кадров исходного MP4, 30 fps, 1920 × 1078, WebP quality 84. Масштабирование при извлечении не применяется. `public/final.png` — последний исходный кадр без потерь, используемый для zoom. `public/digital-form.webp` — предоставленная фотография, оптимизированная без изменения пропорций.

Повторная подготовка из исходного MP4:

```sh
FFMPEG=/path/to/ffmpeg sh scripts/extract-frames.sh /path/to/video.mp4
```

Первый кадр предзагружается и используется как фон до готовности Canvas. `FrameBuffer` загружает кадры в направлении прокрутки, с максимум четырьмя запросами одновременно и максимум 20 декодированными кадрами (~158 MiB RGBA), включая закреплённые первый и последний. Финальный PNG занимает ещё ~8 MiB. ImageBitmap освобождается явно. HTTP-кеш может хранить сжатые ответы; все 180 изображений одновременно не декодируются.

Центр правого на изображении глаза определён по реальному финальному кадру: x=1023, y=356. После завершения последовательности Canvas приближает кадр в 14 раз, центрирует глаз, затем плавно затемняется. При загрузке финального PNG zoom и затемнение ждут его готовности. Все фазы обратимы.

`prefers-reduced-motion` отключает покадровое движение, zoom и длинные закреплённые сцены, оставляя статические изображения и доступный текст. Мобильная версия на этом этапе не разрабатывалась.

## Редактирование

- `src/animations/sequence.js` — Canvas, буфер и eye zoom.
- `src/animations/scenes.js` — манифест и раскрытие фотографии.
- `src/components/projects.js` — направления, будущие медиа, описание и ссылка каждого кейса.
- `src/main.js` — запуск сцен, появление текста и контактный диалог.
- `src/style.css` — типографика и композиция.
- `index.html` — все авторские тексты.

Контакты намеренно не заданы. Кнопка открывает честный диалог с возможностью подготовить и скопировать идею; она ничего не отправляет. После получения адресов замените заглушки Telegram, email и соцсетей реальными ссылками, а основную кнопку свяжите с выбранным каналом.

## Проверка

`scripts/verify-renderer.cjs` проверяет прокрутку в обе стороны, финальный кадр, zoom, fade, раскрытие фото и обратное сворачивание, буфер, ошибки консоли, отсутствие горизонтального скролла, кейсы, диалог и reduced motion. Локальные пути браузерного рантайма задаются под окружение; для другого компьютера используйте свой установленный Playwright и браузеры.
